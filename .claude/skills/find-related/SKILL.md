# /find-related

Find existing entities related to a new piece of information.

Search progressively:
1. exact identifiers
2. Jira IDs
3. aliases and names
4. projects and repositories
5. people
6. keywords
7. semantic concepts
8. dependencies
9. decisions
10. historical sources
11. recent activity

Return candidate matches with confidence.

Do not force a match when evidence is weak. Preserve ambiguity.
