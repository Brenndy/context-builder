# Master workflow

## Register project
1. /project add
2. locate repository
3. run /project-context
4. persist metadata and context

## Work in project
1. resolve project
2. load Project Context
3. identify relevant Topics, Dependencies and Decisions
4. prepare or spawn Claude Code session
5. work independently
6. ingest session knowledge later
7. reconcile global model

## Short user update
1. /ingest
2. resolve entities
3. create/update Topic, Commitment or Dependency only when warranted
4. preserve source/confidence
5. inspect downstream consequences
